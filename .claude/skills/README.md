# Skills für dieses Projekt

Sieben Engineering-Skills aus [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)
(MIT-Lizenz, siehe `LICENSE-agent-skills`), Stand Commit `301b02b` vom 1. November 2026.
Claude lädt sie automatisch, wenn es in diesem Repository arbeitet.

| Skill | Wofür hier |
|---|---|
| frontend-ui-engineering | Oberfläche, Barrierefreiheit, Design-System in `style.css` |
| browser-testing-with-devtools | App im Browser prüfen (Demo-Modus `?demo`) |
| debugging-and-error-recovery | Fehler systematisch eingrenzen |
| incremental-implementation | Änderungen in kleinen, geprüften Schritten |
| code-review-and-quality | Prüfung vor jedem Commit |
| security-and-hardening | Gesundheitsdaten: Login, RLS, kein ungeschütztes HTML |
| performance-optimization | Ladezeit und flüssiges Tippen auf dem iPhone |

Die übrigen Skills des Pakets (TDD, CI/CD, API-Design, Launch …) passen nicht zu einer
kleinen App ohne Build-Schritt und wurden bewusst weggelassen. Die Pfade zu den Checklisten
wurden so angepasst, dass jeder Skill seine `references/` selbst mitbringt.
